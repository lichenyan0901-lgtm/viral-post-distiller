# 标题公式库（基础 8 公式）

> 拆解时用于识别"原标题用的是哪个公式"
> 创作迁移时用于"用不同公式生成 5 个标题备选"
>
> 每个公式都附：识别特征、典型样本、适用场景、迁移示范

---

## 1. 数字型

**核心特征**：标题包含具体数字（条数 / 倍数 / 百分比 / 时间）

**识别特征**：
- 出现"3 个 / 5 招 / 10 条 / 99% / 一年 / 30 天"等具体数字
- 数字往往出现在标题前 6 字内
- 数字暗示"信息密度可量化"，让读者预判收益

**典型样本**：
- "3 个让你少走弯路的 PM 真心建议"
- "30 天不化妆的 5 个肤质变化"
- "测了 12 款防晒，只有这 3 款值得回购"

**适用场景**：干货 / 测评 / 清单 / 攻略
**为什么有效**：数字让用户预判时间成本（"5 分钟看完"），降低进入门槛
**不适合**：情绪型 / 故事型 / 个人成长型（数字会让叙事节奏破碎）

---

## 2. 痛点型

**核心特征**：直接戳中读者的痛苦/焦虑/困境

**识别特征**：
- 出现"崩溃了 / 无语 / 救命 / 怎么办 / 想哭"等情绪词
- 标题描述一个具体的坏情境，让读者瞬间共鸣
- 常用第一人称（我 / 我们 / 打工人 / 姐妹们）

**典型样本**：
- "凌晨 3 点改方案的瞬间，我崩溃了"
- "再也不想被妈妈催婚了，姐妹们救救我"
- "做了 5 年 PM，至今写不好一份 PRD"

**适用场景**：情绪共鸣 / 个人成长 / 职场 / 情感
**为什么有效**：痛点是注意力磁铁，"被点名"的读者无法划走
**不适合**：商业带货 / 中性教程（情绪太强会让产品/方法显得不可信）

---

## 3. 身份代入

**核心特征**：标题里点名特定身份/群体，让目标受众"被叫到"

**识别特征**：
- 出现"xx 人必看 / xx 党 / xx 妈 / xx 党 / xx 党人"等身份标签
- 身份越具体，钩子越精准（"25 岁 INFJ 女生" > "年轻人"）
- 通常以"必看 / 速看 / 注意 / 别再"等动词收尾

**典型样本**：
- "25 岁姐妹必看：我是怎么 1 年攒下 10 万的"
- "宝妈速看，这 3 个辅食工具救了我"
- "刚转行做 AI PM 的同学，我帮你避开 3 个坑"

**适用场景**：垂直人群 / 教程 / 攻略 / 经验分享
**为什么有效**：精准身份触发"这就是我"的代入感，激活点击欲
**不适合**：宽泛话题 / 大众情绪（身份太窄会丢失流量）

---

## 4. 悬念型

**核心特征**：制造信息差，让读者不点进去无法满足

**识别特征**：
- 出现"没想到 / 99% 的人不知道 / 万万没想到 / 真相是 / 后来才发现"等悬念词
- 标题透露一半信息，藏起另一半
- 常用问号或省略号

**典型样本**：
- "99% 的人不知道，PRD 第一段应该这么写"
- "试了 5 款相机后，我没想到最常用的居然是它"
- "辞职 3 个月，我发现一件比工作还累的事..."

**适用场景**：揭秘 / 反常识 / 冷知识 / 经验复盘
**为什么有效**：未完成的句子让大脑产生"必须知道答案"的本能
**不适合**：实用工具型（用户找答案而非找悬念时，悬念反而是干扰）

---

## 5. 反差型

**核心特征**：先否定一种主流认知，再给出意外结果，制造认知冲突

**识别特征**：
- 出现"以为 X，结果 Y / 别再 / 其实 / 反而"等反转结构
- 标题前后两段意思相反
- 常配合"我以为"开头

**典型样本**：
- "以为 AI 工具会让效率翻倍，结果我反而更累了"
- "别再花 3000 块学 AI 了，免费的更好用"
- "我以为努力就能升职，结果加班 3 年还在原地"

**适用场景**：观点输出 / 反共识 / 个人复盘
**为什么有效**：反差激活"我也曾这么想"的共鸣 + "那真相是什么"的好奇
**不适合**：垂直工具教程（学习者要确定性，不要反差）

---

## 6. 利益承诺型

**核心特征**：标题直接承诺读者能获得什么具体收益

**识别特征**：
- 出现"省 xx 元 / 多睡 1 小时 / 1 周瘦 5 斤 / 直接抄作业 / 收藏直接用"等收益
- 收益必须具体可量化
- 常用"看完直接 / 学会立刻"等动词

**典型样本**：
- "看完直接省 3 万：装修避坑全清单"
- "30 天瘦 8 斤的早餐食谱，直接抄"
- "学会这 3 个 prompt，老板再不催你写文档"

**适用场景**：实用工具 / 教程 / 省钱省时类
**为什么有效**：明确收益让读者快速判断"要不要花时间看"
**不适合**：情绪型 / 故事型（情感内容承诺收益会显得功利）

---

## 7. 对比型

**核心特征**：把两个/多个事物并列对比，引发"哪个更好"的好奇

**识别特征**：
- 出现"vs / 对比 / 还是 / 谁更"等并列词
- 标题里有两个具体对象
- 通常带价格/时间/效果等可量化维度

**典型样本**：
- "$8 vs $80 的咖啡，盲测 5 个朋友的反应..."
- "iPhone 还是华为？我用了 1 年告诉你"
- "AI 生成 vs 人工写：谁的 PRD 更能打？"

**适用场景**：测评 / 选购 / 决策辅助
**为什么有效**：对比天然制造立场，吸引"已选边"和"在选边"两种用户
**不适合**：单一观点输出（对比型必须真有两个对象，伪对比会翻车）

---

## 8. 提问型

**核心特征**：标题就是一个开放式问题，邀请读者评论参与

**识别特征**：
- 标题以问号结尾
- 问的是真问题，不是反问
- 通常带"有没有 / 怎么 / 为什么 / 是不是"等疑问词

**典型样本**：
- "第一次来深圳，有没有热心网友推荐几家正宗大排档"
- "做 AI PM 多久才能拿到 30k 月薪？姐妹们的真实工资是多少"
- "你们都怎么对付职场 PUA？"

**适用场景**：UGC 触发器 / 求助型 / 讨论型
**为什么有效**：问题激活答题欲，评论区会自动生成内容
**不适合**：商业带货 / 教程（用户要答案不要问题）

## 公式选择决策树

迁移创作时，根据"新主题的内容类型"选公式：

```
新主题是【实用方法/工具】？
  ├─ 信息密集 → 数字型 / 利益承诺型
  └─ 反主流 → 反差型 / 悬念型

新主题是【情绪/痛点】？
  ├─ 共鸣型 → 痛点型 / 提问型
  └─ 群体认同 → 身份代入

新主题是【测评/选择】？
  └─ 对比型 / 数字型

新主题是【UGC 求助】？
  └─ 提问型（强烈推荐）
```

## 5 标题备选的搭配原则

迁移生成 5 个标题时，**必须用 5 种不同公式**，覆盖不同入口：

- 1 个**数字型**（信息密度入口）
- 1 个**痛点型** 或 **身份代入**（情绪入口）
- 1 个**悬念型** 或 **反差型**（好奇心入口）
- 1 个**利益承诺型**（行动入口）
- 1 个**提问型** 或 **对比型**（互动/决策入口）

让用户从 5 个角度自选最匹配的版本。

---

## 重要约束

- **不要硬贴公式名**：如果原标题不属于这 8 公式（比如纯创意标题），明确说"不属于标准公式，自由创作型"，不要为了贴公式硬编
- **公式可叠加**：同一个标题可能同时用了 2-3 种公式（例如"99% 的姐妹不知道：3 个 PM 必备的 prompt"= 悬念 + 身份代入 + 数字），识别时列出全部
- **迁移时不要照搬原标题词**：用同样的公式，但要替换原主题的词汇，不要让新标题看起来像原标题的简单替换

# 创作迁移 Prompt（核心环节）

> Phase 5：基于 Phase 2 拆出的爆款基因 + 用户给的新主题，直接写出可发布的同款笔记。
>
> **本 skill 真正的价值在这一步**——不是"教你怎么写"，是"直接帮你写"。

---

## 输入（你必须有的素材）

来自 Phase 2 拆解报告：
- 原标题公式（来自模块 1）
- 原内容结构（来自模块 2）
- 原核心情绪（来自模块 3）
- 原爆款基因（来自模块 4）
- 模块 4 末尾的"可复用要素表"

来自用户：
- 新主题（必填）
- 字数要求（可选）
- 账号偏好（可选，如"少用 emoji"、"风格更冷淡"）

如果上面任何关键素材缺失，**先停下询问用户**，不要硬编。

---

## 工作流

### Step 1：基因解构

把原爆款的"基因"列成清单，作为创作约束：

```
约束清单：
- 标题公式池：[原视频用的主公式] + [4 个可叠加公式]
- 必须保留的结构：[钩子手法 + 内容类型 + CTA 类型]
- 必须保留的情绪：[原视频的主导情绪]
- 必须保留的节奏：[段落数 + 平均句长 + emoji/符号策略]
- 不能引入的元素：[原视频没有的、会破坏基因的]
```

**重要**：迁移不是模仿原文案的字句，**是模仿原文案的"结构 + 情绪 + 公式"**。

### Step 2：5 个标题备选生成

用**5 种不同公式**生成 5 个标题。

**搭配原则**（参见 `title-formulas.md` 的"5 标题备选搭配原则"）：

```
- 标题 1：数字型（信息密度入口）
- 标题 2：痛点型 或 身份代入（情绪入口）
- 标题 3：悬念型 或 反差型（好奇心入口）
- 标题 4：利益承诺型（行动入口）
- 标题 5：提问型 或 对比型（互动/决策入口）
```

每个标题必须：
- 标注用的公式名
- 不超过 20 字（小红书）/ 25 字（抖音）
- 不要直接抄原标题的关键词，用同样的"公式套路"换上新主题的词

### Step 3：完整正文

按原爆款的**结构骨架**写正文：

```
正文必须遵守：
1. 段落数：与原爆款相同（不要多不要少）
2. 开头钩子：用原爆款的钩子手法（如身份代入就用身份代入，痛点直击就用痛点直击）
3. 信息节奏：原爆款是高密度爆发就高密度爆发，是缓慢推进就缓慢推进
4. 情绪曲线：起始情绪、中段强化、结尾落点都要对得上
5. CTA：用原爆款的 CTA 类型（直接型 / 引导型 / 隐性型 / 无）
```

**字数要求**：如果用户指定了字数，按指定来；没指定就按原爆款的字数 ±20%。

**风格细节**：
- 原爆款用 emoji，新创作就用 emoji；原爆款不用，新创作也不用
- 原爆款用换行/分隔符切节奏，新创作也用
- 原爆款是冷淡风，不要变成热血鸡汤；原爆款是热血，不要变成佛系

### Step 4：5-8 个话题标签

按以下逻辑组合：

```
推荐组合（5-8 个标签）：
- 1-2 个【超大流量标签】：500w+ 播放量，泛主题（#变美 #职场）
- 2-3 个【中流量精准标签】：50w-500w 播放量，垂直主题（#AI产品经理 #抗老护肤）
- 1-2 个【小流量长尾标签】：<50w 播放量，超精准（#25岁初老 #InfJ女生独居）
- 1 个【场景/身份标签】（如适用）：地域 / 身份 / 场景
```

**禁止做**：
- 不要全选超大流量标签——会被淹没
- 不要全选小流量标签——曝光不够
- 不要复制原爆款的标签——它的标签是为它的主题选的

### Step 5：封面建议

简短描述封面的视觉方向（不实际生成图）：

```
推荐输出格式：
- 视觉类型：[文字密集型 / 视觉密集型 / 文字+视觉结合]
- 主标题大字：[建议在封面上写什么 1 句话，6-12 字]
- 配色情绪：[暖色温暖 / 冷色专业 / 高对比抓眼 / 莫兰迪治愈 / ...]
- 视觉元素：[人物表情 / 产品 / 场景 / 数据图 / 文字排版]
- 与原爆款的对应关系：[简短说明为什么这样设计]
```

## 严格的禁止项

### ❌ 不准把"复刻"做成"全新创作"

迁移的本质是**保留基因换主题**。如果你写出来的内容感觉跟原爆款是两个不同的人写的，说明你换得太多了。

测试方法：把你的新创作贴在原爆款下面对比，如果**段落数、情绪节奏、CTA 风格**对不上，重写。

### ❌ 不准 5 个标题用同一个公式

5 个标题必须**至少覆盖 4 种公式**。如果你发现只能想出同一种公式的 5 个变体，说明对原爆款的公式理解太单一，回去重读 `title-formulas.md`。

### ❌ 不准引入原爆款没有的元素

- 原爆款不用 emoji → 新创作不要乱加
- 原爆款不卖货 → 新创作不要硬塞产品链接
- 原爆款是 50 字 → 新创作不要写 500 字
- 原爆款冷淡 → 新创作不要变热血

### ❌ 不准在标题里写"原标题词的简单替换"

如果原标题是"第一次来深圳，求推荐大排档"，新主题是"AI PM 新人求工具推荐"，**不要**写成"第一次做 AI PM，求推荐工具"——这是字面替换，不是公式迁移。

正确做法：理解原标题用的是"提问型 + 身份代入"公式，然后**根据 AI PM 这个新场景重新组织语言**：
- "刚转 AI PM 的姐妹，你们都在用什么工具搭档？" （提问型）
- "做 AI 产品经理 1 年，求互联网老兵指条路" （身份代入 + 提问型）

每个新标题应该是"独立写出来的"，而不是"原标题的填空"。

### ❌ 不准忽略用户的偏好

用户说了"少用 emoji"，新创作就不要用 emoji，哪怕原爆款用了。
用户说了"更冷淡风"，把所有感叹号、热情词都拿掉。
用户的偏好优先级 > 原爆款的风格。

## 质量自检（输出前必做）

写完后，用这 5 个问题自检一遍：

1. ✅ 5 个标题是否用了至少 4 种不同公式？
2. ✅ 正文段落数是否与原爆款一致？
3. ✅ 情绪基调是否与原爆款对得上？
4. ✅ 标签搭配是否覆盖了大/中/小流量？
5. ✅ 封面建议是否具体到能让用户立刻去做？

任何一项是 ❌，重写对应部分。

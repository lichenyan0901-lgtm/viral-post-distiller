# 爆款作品四模块拆解 Prompt

> 这是 v0.2 的核心拆解 prompt。完成 Phase 1 数据采集后，按本文档的 4 个模块对作品做严谨拆解。

## 总原则

- **每个结论必须有具体证据**：引用文案、数据、标签、信号
- **避免空话**：禁止"内容好""有共鸣""真诚"——除非你能给出可证伪的具体定义
- **承认信息不足**：当前 v0.2 不调评论 API、拿不到完播率，遇到无法判断的维度明确说"信息缺失"
- **战术导向**：拆解的目的是让用户"立刻能复刻发布"，不是写学术报告

---

## 模块 1：封面与标题

### 1.1 标题公式识别

读取 `references/title-formulas.md` 里的 8 公式定义，判断**原标题用了哪种公式**（可能多种叠加）。

**输出格式**：
```
- 主公式：[公式名]
- 叠加公式：[如有，列出 1-2 个次要公式]
- 公式证据：[标题里的哪些词触发了这个公式判断]
```

如果不属于任何公式（罕见），明确写"自由创作型，不属于 8 公式"。

### 1.2 SEO/搜索关键词埋点

分析标题里埋了哪些**用户会主动搜索**的关键词。

**判断标准**：
- 这个词是否是用户在搜索框会主动输入的？
- 是品类词、地域词、需求词、还是品牌词？

**输出格式**：
```
- 品类关键词：xxx, xxx
- 地域/场景关键词：xxx
- 需求关键词：xxx
- 关键词组合策略：[简短描述]
```

例：
- 品类关键词：大排档、深圳美食
- 地域关键词：福田区
- 需求关键词：推荐
- 组合策略：「地域 + 品类 + 求推荐」三段式

### 1.3 封面策略

如果取数返回了封面 URL，结合可推测信息分析：

**判断维度**：
- 封面是文字密集型（标题大字）还是视觉密集型（人/物/场景）？
- 封面文案与标题的关系（重复/补充/反差）？
- 视觉冲击点在哪？

**输出**：如果信息不足以判断（只有封面 URL 没有视觉描述），明确写"封面视觉策略：信息缺失，需要看封面图判断"，**不要硬猜**。

## 模块 2：内容结构

### 2.1 开头钩子（前两行）

抖音/小红书的"前两行"决定完读率。

**判断维度**：
- 钩子手法：身份代入 / 痛点直击 / 悬念抛出 / 利益承诺 / 反差冲击 / 故事入场 / 提问邀请
- 前两行的具体内容（直接引用文案）
- 钩子是不是"自我消解"（看完前两行就不需要看正文了）

**输出格式**：
```
- 前两行原文：「xxx」
- 钩子手法：[手法名]
- 钩子强度：[强/中/弱]
- 钩子完整性：[需要点进正文 / 前两行可独立成立]
```

### 2.2 内容类型

判断这条作品属于哪种类型（可能复合）：

- **干货型**：方法、清单、步骤、避坑
- **故事型**：个人经历、案例、起承转合
- **测评型**：横评、对比、推荐、避雷
- **情绪型**：吐槽、共鸣、宣泄、治愈
- **求助型**：提问、邀请评论、UGC 触发器
- **观点型**：态度输出、行业批判、个人主张

**输出**：主类型 + 次类型（如有）

### 2.3 信息节奏与分段

观察文案的节奏特征：

**判断维度**：
- 每段长度（短句多/长句多）
- 是否用了换行/分隔符/emoji 来切节奏
- 信息密度是均匀还是有高潮节点
- 阅读时长（≤30 秒/30-60 秒/>60 秒）

**输出格式**：
```
- 段落数：N 段
- 平均句长：[短/中/长]
- 节奏特征：[均匀输出 / 高密度爆发 / 缓慢推进 / 反转跳跃]
- 视觉分隔：[使用了哪些（emoji/符号/换行）]
```

### 2.4 结尾互动设计（CTA）

**判断维度**：
- CTA 类型：直接型（评论扣 1）/ 引导型（抛新问题）/ 隐性型（情绪推力）/ 无 CTA
- 与作品目的的匹配度

**输出**：CTA 类型 + 原文（如果有）+ 匹配度评估

## 模块 3：情绪与需求

### 3.1 核心情绪触发

**判断维度**：
- 主要触发了哪种情绪？

**情绪谱系**：
- **共鸣型**：被理解 / 被看见 / 不是只有我（强连接感）
- **好奇型**：信息差 / 反常识 / 我必须知道答案
- **焦虑型**：错过红利 / 别人都会 / 时不我待
- **爽感型**：报复回敬 / 反向操作 / 替我说出心里话
- **笑点型**：搞笑 / 自嘲 / 反差萌
- **优越型**：我懂这个 / 我提前知道
- **治愈型**：放松 / 温暖 / 美好
- **行动欲**：照着做就能改变现状

**输出**：主导情绪 + 强度（1-5）+ 证据（哪句文案触发的）

### 3.2 深层需求满足

用户消费这条内容是为了满足什么需求？

**需求谱系**：
- 省钱 / 省时 / 变美
- 涨知识 / 解决具体问题
- 情绪价值（被陪伴 / 被认同 / 解压）
- 社交资本（让我有谈资）
- 决策支持（帮我选）

**输出**：核心需求 + 次要需求 + 证据

### 3.3 目标用户画像

基于内容反推目标用户：

**输出格式**：
```
- 性别 / 年龄段：xxx
- 身份特征：[职场新人 / 宝妈 / 学生 / 中产 / ...]
- 当下心理状态：[焦虑 / 好奇 / 行动期 / ...]
- 刷到这条内容的典型场景：[通勤/睡前/午休/工作摸鱼/...]
```

⚠️ 评论数据缺失时标注"用户画像基于文案推测，未经评论区验证"

## 模块 4：爆款基因提炼

### 4.1 核心爆款要素（3-5 个关键词）

用 3-5 个关键词总结**这条作品为什么会爆**。

**要求**：
- 必须是名词或形容词短语，不要句子
- 必须具体到可执行（"反共识身份钩子" ✅；"内容好" ❌）

**举例**：
```
1. 反共识身份钩子（"第一次来"+"热心网友"）
2. 地域精准限定（仅限福田区）
3. UGC 触发器结构（问题 > 答案）
4. 评论区即产品（193 评论 vs 116 赞）
5. 0 信息密度文案（仅 50 字 + 3 标签）
```

### 4.2 可复用模板

哪些是**任何赛道都能套用**的元素？

**输出格式**：
```
✅ 可复用：
- 标题公式：[公式名 + 模板填空]
- 内容结构：[结构骨架]
- 情绪策略：[情绪类型 + 触发方式]
- CTA 设计：[CTA 类型]

举例：
- 标题填空：「[场景/身份] + [求/分享] + [具体限定]」
- 结构骨架：「钩子 1 句 → 限定条件 1 句 → 标签 3 个」
- 情绪：通过"被需要感"激活回应欲
```

### 4.3 不可复制因素

哪些是**该账号独有 / 无法复制**的？

**判断维度**：
- 个人 IP（特定脸 / 特定人设 / 特定经历）
- 时机红利（蹭了某个热点 / 平台流量倾斜）
- 资源壁垒（特殊人脉 / 独家信息 / 高成本道具）
- 算法运气（某条数据偶然爆发）

**输出格式**：
```
❌ 不可复制：
- [具体因素 1]：[为什么复制不了]
- [具体因素 2]：[为什么复制不了]
```

---

## 输出汇总表（最后必须有）

```
| 维度 | 本爆款的做法 | 你能复用吗 |
|---|---|---|
| 标题公式 | xxx | ✅ 可复用 |
| 内容类型 | xxx | ✅ 可复用 |
| 核心情绪 | xxx | ⚠️ 看主题 |
| 用户画像 | xxx | ⚠️ 看你的赛道 |
| 关键基因 | xxx | ✅/❌ |
```

这张表是 Phase 5 创作迁移的输入，必须填好。

---

## 严格的禁止项

### ❌ 不准用的词
- "真诚"、"用心"、"做内容的初心"、"价值观"
- "TA 懂用户"、"抓住了情绪"
- "人设很完整" "内容很优质"

如果一定要用，必须立刻补"具体到 [可观察的事实]"。

### ❌ 不准做的事
- 不准在没有数据时硬编结论
- 不准把 8 公式硬贴到不属于公式的标题上
- 不准过度归因（单条视频不能推"博主一贯如何"）
- 不准为了凑模板硬写——拆不出来就明确说"信息不足"

## 排版与风格要求

- 使用 emoji 区隔模块（📊 🎯 📝 💗 🧬 📋 ✨）—— 让报告视觉化、不像论文
- 每个模块的关键结论加粗
- 表格优先于纯文字列表
- 每个判断都给具体证据
- 信息缺失明确标注，不要硬编

## 文件命名规则

```
output/拆解_抖音_<aweme_id 后 8 位>_<YYYYMMDD>.md
```

例如：`output/拆解_抖音_35429361_20260509.md`
